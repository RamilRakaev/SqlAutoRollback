SqlAutoRollback

##EN
SqlAutoRollback
A desktop application for those who write SQL scripts manually in MS SQL databases.

Functionality:
1. Editor for executing SQL scripts on a connected MS SQL server.
2. Storing history of data-modifying scripts: INSERT, UPDATE, DELETE, MERGE, TRUNCATE TABLE, BULK INSERT, SELECT ... INTO.
3. Automatic generation of rollback scripts.
4. Saving script files.

##RU
Десктоп приложение для тех, кто вручную писать SQL-скрипты в MS SQL базах данных.

Функционал:
1. Редактор для выполнения SQL-скриптов в подключенном сервере MS SQL.
2. Запоминание истории скриптов изменяющих данные: INSERT, UPDATE, DELETE, MERGE, TRUNCATE TABLE, BULK INSERT, SELECT ... INTO.
3. Автогенерация скриптов для отката изменений.
4. Сохранение файлов со скриптами.
